# LearnTrack – Student & Course Management System

## Description
A console-based Java application to manage students, courses, and enrollments.

## Features
- Student management
- Course management
- Enrollment tracking
- Menu-driven console UI

## How to Run
1. Compile:
   javac com/airtribe/learntrack/ui/Main.java
2. Run:
   java com.airtribe.learntrack.ui.Main
